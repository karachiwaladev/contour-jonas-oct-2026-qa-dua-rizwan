# Security

This repo runs an unattended agent that reads issues and comments from other people, so it treats all of that text as untrusted data.

- **How the agent is restricted:** [docs/security/README.md](docs/security/README.md)
- **Proxmox and Home Assistant access:** [docs/security/least-privilege.md](docs/security/least-privilege.md)
- **If you suspect a compromise:** [docs/security/incident-response.md](docs/security/incident-response.md)

**Reporting:** if you find a way to make the factory agent do something it shouldn't, don't post the working payload in a public issue. Contact the repo owner privately, or open an issue that describes the problem in general terms.
